# 量化开发岗（实习）完整学习清单
> 按优先级从高到低排序，不考虑时间成本，覆盖所有需要掌握的知识与技能

## 🔴 优先级 1：数据结构与算法（每日必刷）
- **数据结构**  
  - 数组、链表、栈、队列（含环形队列）  
  - 哈希表（`unordered_map` 实现原理、冲突解决）  
  - 二叉搜索树、红黑树（概念 + STL `map` 底层）  
  - 堆（优先队列）、跳表（可选，但了解加分）  
- **算法题（LeetCode）**  
  - 至少 100 道（Easy 30 + Medium 70）  
  - 重点题型：链表、数组、哈希表、字符串、二叉树遍历/层序/路径、DFS/BFS、二分查找、滑动窗口、基础动态规划  
  - 必须用 C++ 刷题，熟练使用 STL

## 🔴 优先级 2：C++ 核心（量化开发的生命线）
- **现代 C++（C++11/14/17）**  
  - `auto`、lambda、智能指针（`unique_ptr` / `shared_ptr` / `weak_ptr`）  
  - 右值引用、移动语义、完美转发  
  - `std::thread`、`std::async`、`std::future`  
  - `std::atomic`、内存顺序（memory order）  
- **内存管理**  
  - 栈与堆、RAII、内存碎片  
  - 自定义内存池、对象池  
- **并发编程**  
  - 互斥锁、读写锁、自旋锁、条件变量  
  - 无锁队列（CAS、ABA 问题）  
  - 线程局部存储（`thread_local`）、线程亲和性  
- **性能优化**  
  - 缓存行对齐、避免伪共享  
  - 分支预测优化（`__builtin_expect`）  
  - 内联汇编基础、`restrict` 关键字  
- **STL 深入**  
  - `vector`/`deque`/`list`/`map`/`unordered_map` 底层结构、时间复杂度、迭代器失效规则  

## 🔴 优先级 3：操作系统（并发与内存部分）
- 进程与线程区别、上下文切换开销  
- 线程同步（互斥锁、条件变量、信号量、读写锁）  
- 死锁的四个必要条件及预防  
- 虚拟内存、物理内存映射（页表）  
- 用户态与内核态切换代价  
- 文件描述符、epoll 与文件系统的关系  
- 内存分配器（`malloc`/`free` 与 `new`/`delete` 区别）

## 🟠 优先级 4：计算机组成（缓存与流水线基础）
- **缓存体系**  
  - L1/L2/L3 结构、缓存行大小、关联度  
  - 伪共享（False Sharing）及避免方法  
  - 缓存亲和性、预取  
- **内存层次**：RAM、NUMA 基础概念  
- **CPU 流水线**：分支预测、分支惩罚  
- **整数表示**：补码、大小端序  
- **推荐阅读**：《深入理解计算机系统》（CSAPP）第 3~6 章

## 🟠 优先级 5：网络编程（低延迟通信基础）
- TCP/UDP socket（非阻塞、`setsockopt`）  
- I/O 多路复用：`select` / `poll` / `epoll`（LT vs ET）  
- 组播（Multicast）接收行情数据  
- 轻量级消息库：ZeroMQ / NATS  
- 内核旁路概念（DPDK、RDMA） – 理解原理即可  

## 🟡 优先级 6：Linux 环境与工具链
- 常用命令：`grep` / `awk` / `sed` / `netstat` / `ss` / `top` / `htop`  
- 编译与调试：`g++`/`clang`、`Makefile`/`CMake`、`gdb`  
- 性能分析：`perf`、`valgrind`、`AddressSanitizer`、`cachegrind`  
- 版本控制：`git` 分支管理、协作流程  

## 🟡 优先级 7：量化系统特定知识
- **行情处理**  
  - Level-2 / MBP / MBO 数据格式  
  - 高效解析二进制行情协议  
- **订单簿重建（Order Book）**  
  - 买/卖盘档位维护、增量更新  
  - 撮合引擎简化逻辑（价格优先、时间优先）  
- **回测系统架构（开发视角）**  
  - 事件驱动 vs 多进程回测  
  - 模拟撮合、滑点、手续费、冲击模型  
  - 时序数据库（ClickHouse / InfluxDB）或列式存储（Parquet）  
- **性能优化实战**  
  - 环形缓冲区（Ring Buffer）  
  - 对象池减少动态分配  
  - 编译优化选项（`-O2`/`-O3`、`-march=native`、LTO）

## 🟢 优先级 8：实战项目（简历核心）
至少完成 2 个完整项目，放在 GitHub 上，附 README + 性能数据  
- **项目 A**：低延迟订单簿维护系统（C++）  
- **项目 B**：基于 epoll 的行情网关 + 环形缓冲区  
- **项目 C**：C++ 回测执行引擎（核心用 C++，Python 绑定）  
- **项目 D**：线程安全内存池 / 对象池（性能对比测试）

## 🔵 优先级 9：计算机体系结构（进阶，有精力再学）
- 缓存一致性协议（MESI / MOESI）  
- 内存屏障（`mfence`、`sfence`、`lfence`）  
- 乱序执行与顺序一致性  
- NUMA 亲和性编程  
- **说明**：实习面试很少直接问，主攻 HFT 低延迟岗位时深入学习

## 📚 辅助技能（按需快速学习）
- **Python**：数据分析（Pandas / NumPy） + `pybind11` 调用 C++ 核心  
- **数据库**：SQL（多表查询、索引优化）  
- **数学基础**：概率统计、线性代数（理解回测中的风险指标即可）
> 有个成均量化公司很有意思，新兴的公司，学完之后可以考虑去实习：https://www.cjquant.com/

> **学习策略**：按优先级自上而下攻克，每个优先级内部可并行。先保证能刷过笔试（算法 + C++ 基础），再用项目证明工程能力。
