# 上海成均资产管理有限公司（成均量化）信息汇总
## 一、公司基础概况
- **公司名称**：上海成均资产管理有限公司（成均量化）
- **办公地址**：上海市中心新天地太平湖畔
- **发展历程**：创始团队2016年起开展国内市场量化交易业务，2020年完成私募基金管理人登记
- **资金规模**：自有资金规模超40亿元，以自有资金交易为主，**不对外募资**
- **人员规模**：公司整体约15人，组织架构扁平；其中研究团队约10人
- **资本情况**：注册资本已按要求完成实缴

## 二、企业文化与团队氛围
1. **名称释义**：“成均”源自《周礼》，本义为古代大学
2. **核心理念**：平等·自由·纯粹·进取
3. **团队风格**：主打纯粹的研究氛围，团队整体年轻化，沟通直接、效率高、工作节奏较快
4. **核心成员背景**：全员来自国内外名校；投资总监拥有15年以上量化研究经验，曾就职于美国顶尖对冲基金量化交易团队

## 三、核心业务与技术方向
### 1. 交易业务
- 交易市场：境内股票及衍生品市场
- 交易标的与频率：覆盖全交易频段
- 管理模式：采用**中央协作制**，无独立PM制；研究、工程、交易、风控多环节协同，策略成果统一走评估、上线流程

### 2. 技术方法论
- 工具栈：日常使用 Python、C/C++、Linux、Git 及内部自研数据/回测/研究平台
- 技术路线：不局限单一方法，兼顾传统统计方法、市场微观结构研究、特征工程，同时大力发展机器学习/深度学习；核心评判标准：方法可验证、可解释、可迭代、能落地实盘
- 算力支持：自建算力机房，算力储备充足，可满足大吞吐分布式训练、大规模策略回测需求

## 四、岗位区分（研究/技术线）
1. **量化研究员 / 深度学习研究员（研究部）**
    - 核心工作：开发量化因子、构建机器学习/深度学习模型、研究并优化交易策略
2. **深度学习工程师（技术部）**
    - 核心工作：模型训练/推理性能优化、算法工程化落地、算力集群运维与迭代、搭建维护数据管线与系统平台
    - 协作模式：两大岗位深度配合，共同推动研究成果落地实盘

## 五、招聘岗位：深度学习工程师（全职/实习）
### 1. 主要职责
1. 配合研究团队，优化深度学习模型训练与推理速度
2. 负责机器学习/深度学习模型工程化落地，以及模型全生命周期管理
3. 迭代、维护深度学习训练集群，提升集群易用性、稳定性与运行效率

### 2. 岗位要求
1. 对深度学习、高性能计算前沿技术有浓厚兴趣，学习与落地能力强
2. 学历：国内985高校 / 国外知名院校，本科及以上学历（计算机、电子工程等相关专业优先）
3. 技术能力：具备优秀编程与工程能力，**精通 C/C++、Python**
4. 软实力：具备团队协作与沟通能力，可独立研究复杂问题并输出解决方案

### 3. 加分项
1. 熟悉 PyTorch 等主流深度学习框架，了解分布式训练、模型加速技术，有相关项目/实习经验优先
2. 掌握 Slurm、Kubernetes 等高性能计算集群调度系统，有实操经验优先
3. 具备 MLOps（机器学习运维）工具使用或项目落地经验

### 4. 公司福利
1. 薪酬：全职岗位**百万年薪起**；实习补贴根据能力、周期综合评定，**单日补贴不低于2000元**
2. 作息：双休、弹性8小时工作制（常规9:00-18:00），不鼓励低效加班；额外提供带薪假期
3. 硬件环境：标配升降桌，零食、水果、饮料不限量供应
4. 生活配套：内设独立健身房，定期组织羽毛球等团体活动、年度旅游
5. 成长体系：一对一导师带教，定期工作复盘，高密度反馈助力新人成长

## 六、官方常见问题（FAQ）
1. **是否招收实习生？**
    招收。优先招募**有实习转正意向、临近毕业**的候选人；实习最低周期不少于3个月，要求全职到岗（每周5天），工作节奏与全职一致；表现优秀者可获得全职Offer。
2. **是否必须通过实习才能获得全职岗位？**
    不是。公司此前以直招全职为主，2026年起新增实习生培养通道；后续仍以全职招聘为核心，同步开放部分转正导向的实习岗。
3. **实习补贴标准？**
    结合岗位方向、个人能力、实习周期综合评定，通常单日补贴不低于2000元。
4. **实习生应聘要求？**
    能力要求与全职基本一致；面试重点考察数理基础、逻辑推理、编程能力、算法功底、机器学习/深度学习理论，同时会深挖简历项目经历。
5. **新人是否有专人带教？**
    实习生、全职员工均配备一对一导师，指导熟悉研究框架、数据体系、工程规范与业务流程，定期开展工作复盘与问题反馈。
6. **主要交易市场、标的与频率？**
    主营境内股票及衍生品市场，覆盖全交易频段。
7. **专业背景要求？**
    - 量化/深度学习研究员：计算机、人工智能、数学、物理、化学、生物等理工科优先；
    - 深度学习工程师：计算机、软件工程、人工智能、自动化等专业优先；
    其他专业若具备扎实数理基础、编程能力、竞赛/科研/项目经验，也可应聘。
8. **研究员与深度学习工程师的区别？**
    研究员隶属于研究部，侧重因子挖掘、模型搭建、策略研发；工程师隶属于技术部，侧重模型优化、工程落地、集群运维，双方紧密协作。
9. **团队、资金、研究规模？**
    公司总人数约15人，架构扁平；自有资金超40亿元；研究团队共10人。
10. **公司成立时间？**
    创始团队2016年入局量化交易，2020年完成私募基金管理人登记。
11. **研究员能否独立管理实盘策略？**
    实行中央协作制，无独立PM；研究员产出统一进入公司标准化流程，经评估、验证后上线实盘。
12. **产品收益表现？**
    自有资金运作，策略风格稳健；具体收益、回撤等数据按合规要求审慎披露。
13. **工作时长与加班情况？**
    双休，常规9:00-18:00，弹性8小时工作制；法定节假日正常休假，调休日一般也正常休息；仅市场、系统、项目出现突发情况时需临时响应，不鼓励无效加班。
14. **算力资源是否充足？**
    自建算力机房，算力充沛，可支撑分布式训练、大规模回测等工作；持续投入数据、算力、平台基建。
15. **研究员考核压力？**
    入职筛选严格，注重员工长期稳定发展；考核侧重长期贡献、研究质量、策略价值与协作能力，成果与薪酬激励挂钩；工作遇阻可随时和导师、团队沟通。
16. **面试流程？**
    标准流程：简历初筛 → HR沟通 → 技术/研究线上面试 → 现场终面 → 发放Offer，个别候选人流程略有调整。
17. **量化公司核心工作内容？**
    依托数学、统计、计算机技术分析市场数据，搭建、迭代交易策略；具体包含数据处理、因子挖掘、模型训练、策略回测、交易执行、风险控制、系统优化等。
18. **常用工具与技术偏好？**
    工具：Python、C/C++、Linux、Git、主流深度学习框架及内部自研平台；技术上不偏向传统方法或AI单一路线，以**落地有效性**为核心评判标准。
19. **团队年龄区间？**
    团队整体偏年轻，不以年龄作为评判标准，重点考察能力、学习速度、投入度、协作意识与长期潜力。
20. **实缴资本情况？**
    注册资本已按监管要求完成实缴，详细工商信息可通过官方公示渠道查询。

4. 培养机制：一对一导师带教，定期复盘反馈
5. 留用机会：实习表现优异者可直接获得全职Offer
